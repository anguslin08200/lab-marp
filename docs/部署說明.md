# Lab Slides 部署說明

在一台新的 Windows 電腦上，從零安裝 Lab Slides 工作台。全部在本機執行，服務只綁定 `127.0.0.1`，不對外開放。

## 1. 需求

| 項目 | 版本／說明 | 必要性 |
|---|---|---|
| Windows 10／11 | 啟動腳本與檔案選擇視窗使用 PowerShell | 必要 |
| Node.js | 20 LTS 以上（開發測試用 v24） | 必要 |
| Git | 取得與更新程式碼 | 必要 |
| Chrome 或 Edge | 匯出 PDF／PPTX、預覽截圖 | 必要（Windows 通常已內建 Edge） |
| Codex CLI | 工作台內的 AI 對話 | 選用 |
| MinerU | 論文 PDF 精確解析（公式、原圖） | 選用 |

確認版本：

```powershell
node -v
git --version
```

## 2. 取得程式碼與安裝依賴

建議放在 `C:\Users\<你>\Documents\NCKUEE\TOOLS\lab-marp`（實驗室的工具都放 `TOOLS\`）。

```powershell
cd $HOME\Documents\NCKUEE\TOOLS
git clone https://github.com/anguslin08200/lab-marp.git
cd lab-marp
npm ci
```

`npm ci` 會依 `package-lock.json` 安裝固定版本（Marp CLI／Core、puppeteer-core、pdfjs、mammoth 等），`node_modules\` 不進 git。

> repo 是公開的，不需要 GitHub 帳號就能 clone；要 push 修改才需要被加為 collaborator。

## 3. 啟動

```powershell
.\Start-Lab-Slides.cmd
```

或在檔案總管雙擊 `Start-Lab-Slides.cmd`。它會：

1. 在背景啟動 `node server.cjs`（port 8766），輸出寫到 `workbench.log`、`workbench-error.log`。
2. 等待服務就緒後打開 http://127.0.0.1:8766/ 。
3. 若 8766 已經是工作台在跑，直接打開瀏覽器，不重複啟動。

不想自動開瀏覽器：`powershell -ExecutionPolicy Bypass -File start.ps1 -NoBrowser`。

**停止服務：** 工作台在背景執行，沒有視窗。要停止時：

```powershell
Get-NetTCPConnection -LocalPort 8766 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess }
```

修改 `server.cjs`、`codex-bridge.cjs`、`attachments.cjs` 或 `themes\` 後，要停止再重新啟動才會生效。

## 4. 安裝 Codex CLI（AI 對話，選用）

```powershell
npm install -g @openai/codex
codex login
```

- 工作台會啟動 `codex app-server`，沿用 CLI 的登入與模型設定，不需要另填 API key。
- 若 Codex 裝在非標準位置，啟動前設定 `CODEX_CLI_PATH` 為原生 `codex.exe` 的完整路徑。
- 第一次對話時，工作台會從 `templates\codex-memory.default.md` 自動建立 `.codex-work\AGENTS.md`（個人報告偏好，不進 git）。
- 用量算在各自的 Codex 帳號。

## 5. 安裝 MinerU（論文精確解析，選用）

工作台預設尋找**相鄰資料夾**：

```
TOOLS\
├─ lab-marp\
└─ mineru\
   ├─ .venv\Scripts\mineru-kit.exe
   └─ home\          ← 模型（約 1.4 GB）
```

安裝（需要 [uv](https://docs.astral.sh/uv/)、Python 3.12）：

```powershell
cd $HOME\Documents\NCKUEE\TOOLS
mkdir mineru; cd mineru
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe "mineru>=4.0,<5"
```

第一次解析時會把模型下載到 `home\`。放在其他位置時，啟動前設定：

```powershell
$env:LAB_MINERU_KIT  = 'D:\mineru\.venv\Scripts\mineru-kit.exe'
$env:LAB_MINERU_HOME = 'D:\mineru\home'
```

解析結果以 PDF 的 SHA256 快取在 `.codex-work\mineru-cache\`，超過 2 GB 時清理最舊的結果。沒有 MinerU 時，附件仍可用快速文字擷取。

## 6. 環境變數一覽

| 變數 | 預設 | 用途 |
|---|---|---|
| `LAB_SLIDES_PORT` | `8766` | 服務 port（`start.ps1` 會固定設成 8766；要改請改腳本內的 `$taskPreviewPort`） |
| `CHROME_PATH` | Chrome 或 Edge 的預設安裝位置 | 匯出用的瀏覽器 |
| `CODEX_CLI_PATH` | 自動尋找 | Codex CLI 位置 |
| `LAB_MINERU_KIT` | `..\mineru\.venv\Scripts\mineru-kit.exe` | MinerU 執行檔 |
| `LAB_MINERU_HOME` | `..\mineru\home` | MinerU 模型目錄 |

## 7. 目錄結構

```
lab-marp\
├─ Start-Lab-Slides.cmd   啟動入口（呼叫 start.ps1）
├─ Export-PowerPoint.cmd  把 slides\index.md 匯出成 output\lab-meeting.pptx
├─ server.cjs             本機 HTTP 服務：開檔、存檔、渲染、匯出、API
├─ codex-bridge.cjs       與 codex app-server 溝通
├─ attachments.cjs        附件解析（PDF、DOCX、圖片、MinerU）
├─ selection-source.cjs   預覽與原始碼的選取對應
├─ ui\                    瀏覽器介面
├─ templates\             CATLab 樣式、範本、Codex 預設記憶
├─ themes\                其他格式（研究會議、簡潔學術、深色展示）
├─ slides\                範例簡報與 starter 範本
├─ scripts\               檢查腳本與檔案選擇器
├─ docs\                  使用說明、部署說明
└─ AGENTS.md              給 AI agent 的操作規則
```

不進 git 的本機資料：`node_modules\`、`output\`、`*.log`、`.codex-work\`（個人記憶、上傳附件、MinerU 快取）。

## 8. 驗證安裝

```powershell
# 1) 命令列渲染：應在 output\ 產生每頁 PNG
npm run check:images

# 2) 啟動工作台後，自動檢查編輯、格式、拖曳、PDF 匯出
npm run check:workbench

# 3) 附件解析（不消耗 Codex 用量）
npm run check:attachments
```

更多檢查腳本（選取同步、捲動同步、MinerU、Codex 實際對話）見 [README.md](../README.md)。會呼叫真實 Codex 的腳本（`check-codex.cjs`、`check-model-upload.cjs`）會消耗用量。

## 9. 更新

```powershell
cd $HOME\Documents\NCKUEE\TOOLS\lab-marp
git pull
npm ci
```

然後停止並重新啟動工作台。`.codex-work\AGENTS.md` 不會被更新覆蓋；如果想套用新版預設記憶，自行比對 `templates\codex-memory.default.md`。
