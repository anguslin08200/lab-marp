# Lab Slides 使用說明（從零開始）

Lab Slides 是一個在本機執行的 Markdown 簡報工作台：左邊寫 Markdown，右邊即時看到投影片，可以匯出 PDF／PPTX／HTML，也能直接請 Codex 幫忙改投影片。版面預設是實驗室的 **CATLab** 格式（成大校徽、藍色標題帶）。

- 還沒安裝？先看 [部署說明.md](部署說明.md)。
- 要讓 AI agent（Claude Code、Codex CLI）從外部幫你做投影片？看 repo 根目錄的 [AGENTS.md](../AGENTS.md)。

---

## 1. 五分鐘上手

1. 雙擊 `Start-Lab-Slides.cmd`。瀏覽器會打開 http://127.0.0.1:8766/ 。
2. 按「**新建**」→ 選「**CATLab**」→ 出現一份論文報告範本。
3. 在左邊改文字，右邊即時更新。用 `---` 分頁。
4. 按「**儲存**」（Ctrl+S）。範本第一次儲存會跳出「另存新檔」，選你的報告資料夾，例如 `meeting\報告3\論文名.md`。
5. 按「**匯出 PDF**」，或從旁邊的 ▾ 選 PowerPoint (.pptx)／HTML。

> 圖片要放在 Markdown 同一層的 `assets\` 資料夾，用相對路徑引用（見第 4 節）。

---

## 2. 介面

| 位置 | 功能 |
|---|---|
| 開啟（Ctrl+O） | 貼上 `.md` 完整路徑，或按「瀏覽…」選檔。會記住最近 20 個檔案 |
| 新建 | 從範本建立新簡報（見第 3 節） |
| 儲存／另存（Ctrl+S／Ctrl+Shift+S） | 寫回 Markdown，並把目前格式的 CSS 寫進檔頭 `style` |
| 簡報格式選單 | 「Markdown 原有格式」或套用 CATLab／研究會議／簡潔學術／深色展示 |
| Codex | 展開／收起 AI 對話區（見第 6 節） |
| 縮略圖 | 顯示投影片縮圖，點選跳頁 |
| 放映（F5） | 從目前頁全螢幕放映，Esc 結束 |
| 匯出 PDF ▾ | PDF、PowerPoint (.pptx)、HTML |
| 重新載入 | 從磁碟重新讀檔（外部工具改過檔案時用） |

- 中間的分隔線可以拖曳，右側有預覽縮放。
- **同步捲動**、**同步選取**預設開啟：選左邊文字，右邊會標出對應位置，反之亦然。
- 沒存檔就關掉也沒關係，下次會提示「恢復未儲存草稿」。

## 3. 範本與格式

### 3.1 從範本建立新簡報

「新建」提供四種格式：

| 格式 | 適合 | 範本內容 |
|---|---|---|
| **CATLab** | 論文報告（實驗室標準） | `templates/catlab.md`：標題、背景、方法、結果四頁骨架，括號 `[ ]` 是待填欄位 |
| 研究會議 | 進度報告、量測結果 | `slides/starter.md` |
| 簡潔學術 | 白底黑字、公式多的論文 | `slides/starter.md` |
| 深色展示 | 圖片、成果展示 | `slides/starter.md` |

範本是唯讀的起點，第一次儲存一定會「另存新檔」，不會改到範本本身。

### 3.2 沿用上一份報告當範本（最常用）

實驗室的報告大多沿用同一套版面。最省事的做法是複製上一份：

1. 複製上一份報告的 `.md` 到新資料夾（例如 `meeting\報告3\`），並建立空的 `assets\`。
2. 用「開啟」打開它，格式選「**Markdown 原有格式**」。
3. 保留檔頭（`---` 到 `---` 之間，含 `style:`），換掉內文。

檔頭的 `style:` 存著整份 CSS，所以複製檔案就等於複製版面。

### 3.3 CATLab 的寫法慣例

```markdown
---
<!-- _class: lead -->

# 論文標題

## 副標題

作者 · 會議 年份 · CATLab Paper Presentation

---
# Outline

- **Introduction**
- <span style="color: #a0a7b2">Method</span>
- <span style="color: #a0a7b2">Experimental Results</span>

---
# Method: 有資訊量的標題

- 主項（藍色方塊）
  - 次項（藍色箭頭），最多兩層

<!-- 講者備註：放在 HTML 註解裡，不會出現在投影片上 -->
```

- 第一個 `#` 是頁面上方的深藍標題帶；`<!-- _class: lead -->` 是封面樣式。
- Outline 導覽頁用粗體標目前章節，其他章節用灰色 `<span>`。
- 某一頁要微調版面時，用 `<style scoped>` 只影響該頁。
- 不要用圓角框、底色卡片這類裝飾；並排內容用分欄或一般表格。

### 3.4 自己新增一種格式（進階）

1. 在 `themes\` 新增 `<id>.css`（可複製 `themes/lab.css` 修改，CSS 要寫用途註解）。
2. 在 `server.cjs` 的 `formats` 陣列加一筆 `{id:'<id>', name:'顯示名稱', description:'說明'}`，並在 `themeFiles` 加 `<id>:'themes/<id>.css'`。
3. 重新啟動工作台（關掉 node 程序後再雙擊 `Start-Lab-Slides.cmd`）。

新格式會使用 `slides/starter.md` 當起點；若要專屬骨架，參考 `server.cjs` 裡 `/api/template` 對 `catlab` 的處理。

## 4. 圖片、公式、表格

```markdown
![height:340px](assets/figure.png)        一般圖片（可用 width: 或 height:）
![bg right:42%](assets/figure.png)        右側背景圖
$E = mc^2$   或   $$h_t = A h_{t-1} + B x_t$$   公式（KaTeX）
```

- 圖片和字型必須在 Markdown 所在資料夾或其子資料夾內；另存到其他資料夾時要一起搬圖。
- 論文截圖要裁掉多餘的圖說，並在頁角標註來源，例如：
  `<p class="src">Gu & Dao, Figure 3</p>`（`.src` 的樣式寫在該頁的 `<style scoped>`）。
- 表格用一般 Markdown 表格；欄寬、字級用 `<style scoped>` 調整。

## 5. 匯出

| 格式 | 怎麼做 | 說明 |
|---|---|---|
| PDF | 「匯出 PDF」 | 用本機 Chrome 或 Edge 轉檔，會匯出目前草稿（不必先存） |
| PowerPoint | ▾ → PowerPoint (.pptx) | 每頁是一張圖片，版面完全一致，但文字不能在 PPT 裡編輯 |
| HTML | ▾ → HTML | 單一 HTML 檔，可直接用瀏覽器放映 |

## 6. AI 使用說明：工作台內的 Codex 對話

### 6.1 前置條件

需要先安裝並登入 Codex CLI（見 [部署說明.md](部署說明.md) 第 4 節）。對話使用你自己的 Codex 帳號額度；送出時，你的要求、目前 Markdown 和附件內容會傳給 Codex 服務。

### 6.2 基本用法

1. 按上方「**Codex**」展開對話區。
2. 輸入要求，Enter 送出（Shift+Enter 換行）。例如：
   - 「把第 5 頁整理成三個重點」
   - 「把 Table 7 做成表格，最有效的兩列標藍」
   - 「依照 30 分鐘規劃整份報告，列出每頁時間」
   - 「標題改英文，講者備註也改英文」
3. Codex 回覆後，修改會**直接套用到草稿**並更新預覽。
4. 不滿意按「**復原上次修改**」；要中斷按「**停止**」。
5. 滿意後按「**儲存**」才會寫入檔案。

- 回覆期間你仍可手動編輯；若內容已變，回覆會保留成「套用回覆中的修改」，套用前會確認。
- 「新對話」清除對話上下文（不影響 Markdown）。
- 「模型」「Effort」選單可切換模型與推理強度；「預設」沿用 CLI 設定。改大量內容時建議提高 Effort。

### 6.3 加入論文或資料

按「**加入檔案**」，支援：

| 類型 | 說明 |
|---|---|
| PDF | 擷取文字；有 MinerU 時可「精確解析」保留公式和論文圖片 |
| Word `.docx` | 擷取文字（不含內嵌圖片） |
| 文字（MD／TXT／CSV／JSON／YAML／LOG） | UTF-8 |
| 圖片（PNG／JPEG／WebP） | 直接給模型看，也可以要求放進投影片 |

限制：每檔 10 MB、每次 5 檔、合計 25 MB。掃描版 PDF 沒有文字層，要先 OCR 或改傳頁面圖片。

**MinerU 精確解析（選用）：** 開啟後，PDF 會在背景解析（排隊 → 解析中 → 完成）。完成後按附件旁的「**圖片**」可瀏覽論文原圖，點一下就插入游標位置；也可以直接對 Codex 說「放入論文 Figure 1」。解析還沒完成就送出時，可選「等待後傳送」或「立即使用快速文字」。

### 6.4 讓 Codex 記住你的報告偏好

工作台的 Codex 會讀取 `.codex-work\AGENTS.md`（第一次使用時由 `templates\codex-memory.default.md` 自動建立）。裡面是報告時間、結構、排版規則。

- 想長期改變 Codex 的做法（例如「全部用英文」「每章前加 Outline」），就編輯這個檔案，然後按「**新對話**」生效。
- 這個檔案是你個人的，不會進 git。
- 對話中明確說的要求優先於這份記憶。

### 6.5 用 Codex 時的提醒

- **AI 會出錯**：數字、論文事實、圖表編號都要對照原論文確認。
- 一次給一個明確要求，效果比一長串混在一起好。
- Codex 回傳的 Markdown 會先經過排版檢查才套用，但仍要自己看過每一頁有沒有溢出。

## 7. 和外部 AI agent／編輯器一起用

如果你讓 Claude Code、Codex CLI 或 VS Code 直接改 `.md` 檔：

1. **先在工作台按「儲存」**，把手邊修改寫進檔案。
2. 讓外部工具修改。
3. **回到工作台按「重新載入」**。

工作台儲存會**整份覆寫** Markdown。如果外部改了檔案、你卻在工作台按儲存，外部的修改會被蓋掉。

給 AI agent 的完整規則在 [AGENTS.md](../AGENTS.md)。VS Code 使用者可裝 Marp for VS Code 擴充（`.vscode/extensions.json` 已推薦）。

## 8. 常見問題

| 狀況 | 解法 |
|---|---|
| 雙擊後沒反應或顯示錯誤 | 看 `workbench-error.log`；確認已 `npm ci`（[部署說明.md](部署說明.md)） |
| 「Port 8766 is in use by another application」 | 有別的程式占用 8766；關掉它，或改 `start.ps1` 的 `$taskPreviewPort` |
| 畫面顯示「請重新整理啟動介面」 | 工作台重啟過，重新整理瀏覽器頁面 |
| 圖片不顯示 | 圖片要在 `.md` 同層或子資料夾，路徑用相對路徑 |
| 匯出 PDF 失敗「需要 Chrome 或 Edge」 | 安裝 Chrome／Edge，或設定環境變數 `CHROME_PATH` |
| Codex 顯示未登入 | 終端機執行 `codex login`，再按「重新連線」 |
| Codex 說「工作台專案記憶為空或過大」 | 檢查 `.codex-work\AGENTS.md`，不能是空檔，也不能超過 32 KB |
| MinerU 選項是灰的 | 沒有安裝 MinerU，或路徑不對；附件仍可用快速文字 |
