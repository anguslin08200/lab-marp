# Lab Slides：Markdown 簡報工作台

> **文件：** [從零開始的使用說明](docs/使用說明.md)（含範本、AI 使用）｜[部署說明](docs/部署說明.md)｜[給 AI agent 的規則](AGENTS.md)

雙擊 `Start-Lab-Slides.cmd`，同一個視窗會顯示 Markdown 編輯器與投影片預覽。網址為 http://127.0.0.1:8766/ ，編輯與 PDF／PPTX／HTML 匯出在本機進行。使用 Codex 對話時，送出的要求、目前 Markdown 與對話內容會透過 Codex CLI 傳至其服務。

## 操作

- **開啟 Markdown（Ctrl+O）**：在視窗內瀏覽資料夾、回上一層或切換磁碟，點選 `.md` 即可開啟；也保留完整路徑輸入與原生「瀏覽…」。支援 Windows「複製為路徑」附帶的引號，原生選檔等待時仍可取消或直接輸入路徑。
- **拖放開啟**：把 `.md` 拖入工作台會讀取內容，建立「未命名草稿」，儲存時使用另存新檔。瀏覽器無法提供原檔路徑，因此相對圖片需改用「開啟」指定原檔，或改為內嵌圖片。
- **即時編輯**：輸入後僅替換有變更的投影片，保留未變更圖片與預覽位置；首次載入或格式／前置設定改變時重新載入預覽。尚未儲存的內容也能放映與匯出。
- **換行與行號**：預設自動換行，設定會保留。關閉自動換行時顯示同步捲動的行號；換行模式暫時隱藏行號。內嵌 base64 圖片可能佔用很長的編輯高度。
- **投影片導航**：預覽標題列顯示目前頁與總頁數，上一頁／下一頁按鈕及 PageUp／PageDown 可跳頁（文字輸入欄位內保留原本按鍵行為）。「縮略圖」可開關側欄，點選會同時定位預覽與 Markdown 來源，顯示設定會保留。
- **放映（F5）**：從目前頁開始，以目前草稿全螢幕顯示。←／→、空白、PageUp／PageDown 翻頁，Esc 結束；瀏覽器不允許全螢幕時使用覆蓋視窗。
- **拖曳分隔線**：調整左右比例，也支援方向鍵；右側另有縮放滑桿。
- **同步捲動**：預設開啟，左側 Markdown 與右側投影片依對應頁面雙向捲動；取消編輯區上方的勾選可分別捲動。設定會保留。
- **新建範本**：選擇 CATLab、研究會議、簡潔學術或深色展示。
- **簡報格式**：保留 Markdown 原有格式，或套用指定格式。
- **儲存／另存新檔**：將內容與格式寫進 Markdown，快捷鍵 Ctrl+S／Ctrl+Shift+S。
- **匯出**：主按鈕下載 PDF，旁邊下拉選單可下載 PowerPoint `.pptx` 或 HTML；均使用目前草稿與選用格式。HTML 會內嵌本機圖片與字型，PPTX 以整頁圖片保留版面。
- **從磁碟重新載入**：使用外部編輯器修改後，可重新讀取。
- **Codex 對話**：使用現有 CLI 登入，直接要求修改文字、背景、字型或版面；回覆逐步顯示，完成後自動更新 Markdown 與預覽。

編輯不會直接覆寫原檔，儲存才會寫入；關閉或切換檔案時會提醒尚未儲存的修改。新建範本與拖入的未命名草稿會使用另存新檔。未儲存狀態以黃色圓點徽章顯示，操作結果顯示於右下角短暫通知，錯誤會停留較久。工作台外框支援系統深色主題，不改變投影片配色。

草稿會按檔案路徑與時間自動備份在此瀏覽器的 localStorage。重新開啟檔案時，若備份較新且與磁碟內容不同，會出現「恢復未儲存草稿／捨棄」提示；恢復後仍需手動儲存。儲存成功會清除該檔備份。備份只留在同一瀏覽器與網址，不會傳給 Codex；清除瀏覽器資料會移除備份，容量不足時會通知手動儲存。

拖入的未命名草稿各自保留獨立備份，不會互相覆蓋。「開啟」視窗下方會列出所有未命名草稿備份，可按名稱與時間恢復；從範本啟動時也會提示最近一份未命名草稿。

選用格式後，儲存時會把 CSS 寫入 Markdown 的 `style: |` 多行區塊；舊版單行跳脫字串仍可讀取。之後重新開啟使用「Markdown 原有格式」即可得到相同效果。

## Codex CLI 對話

工作台會啟動已安裝的 `codex app-server`，沿用 CLI 的帳號與模型設定，無須另填 API key。若顯示未登入，先在終端機執行 `codex login`，再按「重新連線」。安裝於自訂位置時，可設定 `CODEX_CLI_PATH` 為原生 `codex.exe` 路徑。對話使用既有帳號的用量。

例如：「把標題改成中文」、「將第二頁整理為三個重點」、「背景改為淡藍色，內文字型改為 28px」。Enter 送出，Shift+Enter 換行。修改套用到目前草稿，按「儲存」才寫入檔案；「復原修改」可回復上次 Codex 修改，「停止」可取消回覆。「新對話」清除對話上下文。

對話區的「模型」選單讀取目前 Codex CLI 的模型清單；預設沿用 CLI 設定，也可選擇模型，在下一次傳送時切換並保留同一段對話。模型選擇會在此工作台瀏覽器保留；實際使用仍依帳號授權與 CLI 的回應。

「加入檔案」支援 PDF、Word `.docx`、UTF-8 文字（MD／TXT／CSV／JSON／YAML／LOG），以及 PNG／JPEG／WebP 圖片。每檔最多 10 MB，每次最多 5 檔、合計 25 MB。檔案先保存在 `.codex-work/uploads` 並於本機解析，按「傳送」才將选取附件及目前 Markdown 交給 Codex。圖片透過 CLI 原生圖片輸入，可依要求加入簡報並內嵌 Markdown，避免另存後圖片路徑失效。

PDF／Word 會送出擷取文字；PDF 另存 Markdown 轉換稿。掃描 PDF 若沒有可讀文字，需要先 OCR，或改上傳頁面圖片。單檔擷取文字最多 200,000 字元，附件合計 350,000 字元。附件上的「×」可移除，開始新對話或換檔會清除選取附件；移除不會撤回已傳送的對話內容。文字圖表的精確排版、DOCX 內嵌圖片並不包含在純文字擷取中。

處理期間仍可手動編輯；若內容已改變，回覆會保留為待套用修改，套用前會確認取代手動編輯。CLI 在隔離的唯讀工作目錄執行，只回傳結構化 Markdown 提案；工作台不提供它執行終端命令或直接改寫檔案的操作。

### 工作台專案記憶

專用的 `.codex-work/AGENTS.md` 保存 PDF 報告指引與使用者補充，僅作用於此工作台，不修改其他專案或全域 Codex 設定。新對話會讀取此檔；重設對話／重啟不會刪除它。修改指引後請開始「新對話」，讓新的設定生效。

目前預設約 **30 分鐘日常報告**，依語速、每頁時間與內容密度彈性安排。20 分鐘約 10–13 頁、限時正式會議約 7–10 頁都只作參考，不是硬性頁數限制；以實際彩排計時調整。30 分鐘按主講時間估算，Q&A 若另計會在規劃時說明；對話中指定的時間與要求優先。記憶另包括完整報告結構、圖表解釋、可讀字型、內容密度、來源與事實檢查。

`node scripts/check-codex.cjs` 會使用實際 CLI 進行兩次對話，另驗證復原、停止與手動編輯保護。`npm run check:workbench` 驗證編輯、格式、拖曳與 PDF 匯出；執行前請先啟動工作台。

`node scripts/check-scroll-sync.cjs` 驗證依分頁雙向捲動、縮放與拖曳後的位置、重新渲染、底部對齊，以及同步開關的保留。

「同步選取」預設開啟：選取 Markdown 文字時，預覽會高亮對應內容；選取預覽文字時，編輯器會選取並標示來源。兩側會顯示對應位置，且不切換鍵盤焦點。標題、分點、表格儲存格與公式使用來源位置對應，同名標題也能分辨；公式或含格式的文字無法逐字對應時，會標示所在區塊。尚未完成預覽更新的草稿不使用舊位置。此開關獨立於同步捲動，高亮不會寫入 Markdown 或 PDF。

`npm run check:selection` 使用獨立測試伺服器驗證雙向選取、同名標題、表格、公式、格式切換、重新渲染、焦點及關閉同步；不儲存測試草稿。

`npm run check:attachments` 驗證本機 PDF／DOCX／文字／圖片解析與限制；`node scripts/check-model-upload.cjs` 使用實際 CLI 進行兩次對話，驗證模型切換、文字與圖片讀取、圖片加入簡報及附件移除。

## CATLab 格式

來源為使用者提供的 `How to Do Paper Presentation.pdf`。轉換稿為 `templates/reference.md`，代表頁保存在 `templates/reference_assets/`。

採用原 PDF 的 16:9、左側藍色漸層、深藍標題帶、成大校徽與頁碼配置。校徽直接從 PDF 取得並內嵌 CSS；版面以 CSS 重建，文字可透過 Markdown 修改。顏色與間距近似原稿；英文優先使用 Arial Narrow，中文使用 Windows 字型後備。

## 圖片與公式

以 `---` 分頁。一般圖片：`![height:340px](assets/figure.png)`；背景圖片：`![bg](assets/background.jpg)`；側邊背景：`![bg right:42%](assets/figure.png)`；公式用 `$...$` 或 `$$...$$`。

本機圖片與字型檔請放在 Markdown 所在資料夾或其子資料夾。選擇檔案後，工具會依原 Markdown 的位置讀取相對路徑。若另存到不同資料夾，請一併移動圖片。CATLab 校徽已內嵌，無須搬移。

## PowerPoint 與命令列

原本的 `Export-PowerPoint.cmd` 保留：匯出 `slides/index.md` 至 `output/lab-meeting.pptx`。一般 PPTX 以整頁圖片保留版面。工作台的匯出選單直接匯出目前草稿，支援 PDF、PPTX 與 HTML，相對圖片依原始檔案資料夾解析。

`npm run dev` 啟動工作台；`npm run dev:marp` 啟動原 Marp server；`npm ci` 重新安裝依賴。

主要檔案為 `server.cjs`（本機服務）、`ui/`（操作介面）、`themes/`（一般格式）、`templates/catlab.css`（CATLab）。程式與樣式包含用途註解。

基礎工具：[Marp Core](https://github.com/marp-team/marp-core)、[Marp CLI](https://github.com/marp-team/marp-cli)。PDF 匯出使用本機 Chrome 或 Edge。

### Codex effort 與對話區大小

模型旁的 Effort 選單會列出目前 CLI 模型支援的推理強度；「預設」沿用 CLI 設定或模型預設。選擇在下一次送出訊息生效，並依模型記住。
對話區初始高度為編輯面板的 38%，保留主要編輯空間。拖曳 Markdown 與 Codex 之間的橫向把手可調整對話高度，也可聚焦把手後按上下方向鍵。對話標題列的「收起／展開」及頂部「Codex」按鈕保留對話與附件，不會中斷正在生成的回覆。使用者調整過的高度與收起狀態會在同一瀏覽器保存。
驗證：`node scripts/check-chat-controls.cjs`（預設測試伺服器為 8767；檢查 effort 傳送、預設還原、拖曳、收起與設定持久化）。

### 上次檔案與最近開啟

工作台會在同一瀏覽器記住成功開啟或儲存的 Markdown 路徑，下次載入時自動開啟上次檔案。「開啟」視窗提供最近 20 個檔案，依最近使用排序，可點選開啟、移除單筆或清除全部紀錄。最近檔案紀錄只保存路徑與使用時間，草稿備份另行保存；新建但未儲存的範本及未命名草稿不會取代上次檔案。上次檔案若無法讀取，會回到範本並顯示選檔視窗供重新選擇。
驗證：`node scripts/check-recent-documents.cjs`。

### 獨立端口驗證

設定 `LAB_SLIDES_PORT=8771` 後執行 `node server.cjs`。另一個同樣設定端口的終端執行 `node scripts/check-ux.cjs`，驗證樣式序列化、增量預覽、導航、放映、瀏覽 API、草稿恢復及 PPTX／HTML 匯出。`node scripts/check-regressions.cjs` 會在記憶體中替換舊測試的固定網址，執行六項既有工作台檢查，不修改原測試檔或碰觸 8766 伺服器；對話控制檢查使用固定模型目錄與模擬傳送，不消耗 Codex 推論用量。

若受限的測試環境無法啟動 Chrome 沙箱，可僅在測試終端設定 `LAB_TEST_NO_SANDBOX=1`，並以 `node -r ./scripts/check-browser-support.cjs server.cjs` 啟動、同樣加上 `-r` 執行 UX 測試；PPTX 測試另設 `CHROME_NO_SANDBOX=1`。這些設定不影響正常啟動，驗證後請關閉自己的測試伺服器。

### MinerU 論文精確解析

Codex 附件列的「精確解析（MinerU）」預設開啟，選擇會保存在目前瀏覽器。服務未提供 MinerU 時選項會停用並顯示原因，附件仍可使用快速文字。PDF 上傳後會顯示排隊、解析中、完成或失敗狀態；解析失敗時會改用快速文字，內容截斷時也會提示。

解析尚未完成就傳送時，可選擇等待完成後自動傳送、立即使用快速文字，或取消。等待期間可按「停止」取消；移除附件、重設對話或切換文件也會取消等待。解析完成後，按附件旁的「圖片」可瀏覽論文圖片及頁碼，圖片依「圖與圖表／表格／公式」分頁，預設顯示架構圖與圖表；點選圖片即可插入編輯器游標位置。對 Codex 說「放入論文 Figure 1」時，它會直接使用論文原圖。已儲存的文件會使用複製至文件資產的圖片，未命名草稿則內嵌圖片。

MinerU 預設使用相鄰的 `../mineru/.venv/Scripts/mineru-kit.exe` 與 `../mineru/home`；可在啟動服務前設定 `LAB_MINERU_KIT`、`LAB_MINERU_HOME` 覆蓋路徑。解析依序在背景執行，以 PDF 的 SHA256 快取至 `.codex-work/mineru-cache/`，再次上傳相同內容可立即使用；移除附件不會刪除快取，總量超過 2 GB 時清理最舊結果。

精確 Markdown 保留公式與論文圖片引用；支援圖片的模型額外接收最多 12 張圖，其他圖片仍可透過引用放入投影片。超過文字上限時先移除參考文獻，再視需要截斷。驗證：`node scripts/check-mineru.cjs`，涵蓋本機附件、快取、圖片與安全 API，不消耗 Codex 推論用量。

Codex 若拒絕請求或執行緒出錯，工作台會在幾秒內顯示原因，不再等到 10 分鐘逾時；Markdown 不會被修改，可直接重試或提高 Effort。
